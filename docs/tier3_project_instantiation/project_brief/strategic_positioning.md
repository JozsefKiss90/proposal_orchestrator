# FIELDWISE — Strategic positioning

<!-- source_ref: §1.1.9 ¶102-110 -->
## Ambition beyond the state of the art

FIELDWISE introduces six transitions:

1. Spectral proxy -> Physiological target
2. Hyperspectral discovery -> Satellite scaling
3. Static detection -> Prospective prediction
4. Internal validation -> Temporal transferability
5. Single-country modelling -> Geographic transferability
6. Research accuracy -> Commercial-field decision value

Validation ladder: MATE - scientific development and validation -> MVCRI - cross-country transferability -> AgroVIR farmer field - operational transferability -> DrR Web MVP - research-to-operation delivery.

<!-- source_ref: §2.3 ¶239-249 -->
## Magnitude and importance of expected impacts

### Scientific impact

FIELDWISE provides a framework for agricultural AI evaluated according to temporal + geographic + operational transferability rather than only retrospective accuracy. It additionally establishes a methodological bridge between high-information proximal hyperspectral observations and scalable Sentinel-based prediction.

### Environmental impact

FIELDWISE contributes to the EU-level opportunity for water savings in irrigated agriculture by improving the timing and spatial prioritisation of irrigation decisions. The project does not claim in advance that it will achieve a particular percentage reduction; impact will be quantified from project evidence.

### Agricultural and food-production impact

Water scarcity already produces agricultural yield losses and higher water costs in Europe, while irrigation demand is expected to increase under climate change. Processing tomato provides a high-value horticultural test case in which improved timing can therefore have substantial agronomic and economic relevance.

### Technological impact

FIELDWISE advances the project from a desktop research prototype to a scientifically validated web MVP. External AgroVIR evaluation provides evidence about whether the resulting technology meets actual agricultural software requirements.

### European impact

The MATE-MVCRI architecture directly investigates whether agricultural AI developed in one European environment can be transferred to another. FIELDWISE therefore contributes to a wider European question: how can locally developed agricultural intelligence become reliably transferable rather than remaining confined to the field in which it was trained?
