### Two Streaming APIs

1. **ConverseStream** (`converse_stream()`) — Streaming variant of the Converse API.
2. **InvokeModelWithResponseStream** (`invoke_model_with_response_stream()`) — Streaming variant of InvokeModel.

### ConverseStream Event Sequence

When using `ConverseStream`, the response is delivered through a stream of events in this order:

1. `messageStart` — Start event for a message. Includes the `role` for the message.
2. `contentBlockStart` — Content block start event. Tool use only.
3. `contentBlockDelta` — Content block delta event. Includes one of:
   - `text` — Partial text generated by the model.
   - `reasoningContent` — Partial reasoning carried out by the model. The returned `signature` must be submitted in subsequent `Converse` requests.
   - `toolUse` — Partial input JSON object for tool use.
4. `contentBlockStop` — Content block stop event.
5. `messageStop` — Stop event for the message. Includes `stopReason`.
6. `metadata` — Request metadata including `usage` (token counts) and `metrics` (latency).

A complete content block is streamed as: `ContentBlockStartEvent` → one or more `ContentBlockDeltaEvent` → `ContentBlockStopEvent`. Use the `contentBlockIndex` field to correlate events within a content block.

### ConverseStream Python Example

```python
import boto3
from botocore.exceptions import ClientError

client = boto3.client("bedrock-runtime", region_name="us-east-1")
model_id = "cohere.command-r-v1:0"

conversation = [
    {
        "role": "user",
        "content": [{"text": "Describe the purpose of a 'hello world' program in one line."}],
    }
]

try:
    streaming_response = client.converse_stream(
        modelId=model_id,
        messages=conversation,
        inferenceConfig={"maxTokens": 512, "temperature": 0.5, "topP": 0.9},
    )

    for chunk in streaming_response["stream"]:
        if "contentBlockDelta" in chunk:
            text = chunk["contentBlockDelta"]["delta"]["text"]
            print(text, end="")

except (ClientError, Exception) as e:
    print(f"ERROR: Can't invoke '{model_id}'. Reason: {e}")
    exit(1)
```

### InvokeModelWithResponseStream Python Example (Claude)

```python
import boto3
import json

client = boto3.client("bedrock-runtime", region_name="us-east-1")
model_id = "anthropic.claude-3-haiku-20240307-v1:0"

prompt = "Describe the purpose of a 'hello world' program in one line."

native_request = {
    "anthropic_version": "bedrock-2023-05-31",
    "max_tokens": 512,
    "temperature": 0.5,
    "messages": [
        {
            "role": "user",
            "content": [{"type": "text", "text": prompt}],
        }
    ],
}

request = json.dumps(native_request)

streaming_response = client.invoke_model_with_response_stream(
    modelId=model_id, body=request
)

for event in streaming_response["body"]:
    chunk = json.loads(event["chunk"]["bytes"])
    if chunk["type"] == "content_block_delta":
        print(chunk["delta"].get("text", ""), end="")
```

### InvokeModelWithResponseStream .NET Example (Claude)

```csharp
var client = new AmazonBedrockRuntimeClient(RegionEndpoint.USEast1);
var modelId = "anthropic.claude-3-haiku-20240307-v1:0";

var nativeRequest = JsonSerializer.Serialize(new
{
    anthropic_version = "bedrock-2023-05-31",
    max_tokens = 512,
    temperature = 0.5,
    messages = new[]
    {
        new { role = "user", content = "Your message here" }
    }
});

var request = new InvokeModelWithResponseStreamRequest()
{
    ModelId = modelId,
    Body = new MemoryStream(System.Text.Encoding.UTF8.GetBytes(nativeRequest)),
    ContentType = "application/json"
};

var streamingResponse = await client.InvokeModelWithResponseStreamAsync(request);

foreach (var item in streamingResponse.Body)
{
    var chunk = JsonSerializer.Deserialize<JsonObject>((item as PayloadPart).Bytes);
    var text = chunk["delta"]?["text"] ?? "";
    Console.Write(text);
}
```

### ConverseStream JavaScript Example

```javascript
import {
  BedrockRuntimeClient,
  ConverseStreamCommand,
} from "@aws-sdk/client-bedrock-runtime";

const client = new BedrockRuntimeClient({ region: "us-east-1" });
const modelId = "cohere.command-r-v1:0";

const command = new ConverseStreamCommand({
  modelId,
  messages: [{ role: "user", content: [{ text: "Your message" }] }],
  inferenceConfig: { maxTokens: 512, temperature: 0.5, topP: 0.9 },
});

const response = await client.send(command);

for await (const item of response.stream) {
  if (item.contentBlockDelta) {
    process.stdout.write(item.contentBlockDelta.delta?.text);
  }
}
```

## Integration Relevance

- **Backend transport:** Streaming requires different method calls (`converse_stream` / `invoke_model_with_response_stream`) and event-based response processing instead of single-response parsing.
- **Authentication:** Same IAM authentication as non-streaming. Requires `bedrock:InvokeModelWithResponseStream` IAM action.
- **Request construction:** Request format is identical to non-streaming variants.
- **Response parsing:** Response is an event stream that must be iterated. Events arrive in defined order: `messageStart` → `contentBlockDelta` (multiple) → `messageStop` → `metadata`.
- **Error handling:** Same `ClientError` handling. Errors may occur mid-stream.
- **Streaming:** `contentBlockDelta` events contain partial text in `delta.text`. Use `contentBlockIndex` to correlate events across content blocks.
- **Tool use:** Streaming supports tool use via `contentBlockDelta` events with `toolUse` delta type.
