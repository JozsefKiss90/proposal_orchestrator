  ============================================================================
  Step 1: Create the S3 Bucket for Trail Logs
  ============================================================================

  S3 bucket names must be globally unique. Use the account ID as a suffix:

  BUCKET_NAME="proposal-orchestrator-cloudtrail-232538551827"

  # 1a. Create the bucket
  aws s3api create-bucket \
    --bucket "${BUCKET_NAME}" \
    --region us-east-1 \
    --output json

  Note: For us-east-1 you do NOT need --create-bucket-configuration.
  For any other region you would need:
    --create-bucket-configuration LocationConstraint=<region>

  # 1b. Block all public access
  aws s3api put-public-access-block \
    --bucket "${BUCKET_NAME}" \
    --public-access-block-configuration \
      "BlockPublicAcls=true,IgnorePublicAcls=true,BlockPublicPolicy=true,RestrictPublicBuckets=true"

  # 1c. Tag the bucket
  aws s3api put-bucket-tagging \
    --bucket "${BUCKET_NAME}" \
    --tagging 'TagSet=[{Key=project,Value=proposal-orchestrator},{Key=environment,Value=production},{Key=purpose,Value=cloudtrail-logs}]'

  ============================================================================
  Step 2: Apply S3 Bucket Policy
  ============================================================================

  Save the following to a file called trail_bucket_policy.json:

  ---- BEGIN trail_bucket_policy.json ----
  {
      "Version": "2012-10-17",
      "Statement": [
          {
              "Sid": "AWSCloudTrailAclCheck",
              "Effect": "Allow",
              "Principal": {
                  "Service": "cloudtrail.amazonaws.com"
              },
              "Action": "s3:GetBucketAcl",
              "Resource": "arn:aws:s3:::proposal-orchestrator-cloudtrail-232538551827",
              "Condition": {
                  "StringEquals": {
                      "aws:SourceArn": "arn:aws:cloudtrail:us-east-1:232538551827:trail/proposal-orchestrator-bedrock-trail"
                  }
              }
          },
          {
              "Sid": "AWSCloudTrailWrite",
              "Effect": "Allow",
              "Principal": {
                  "Service": "cloudtrail.amazonaws.com"
              },
              "Action": "s3:PutObject",
              "Resource": "arn:aws:s3:::proposal-orchestrator-cloudtrail-232538551827/cloudtrail/proposal-orchestrator/AWSLogs/232538551827/*",
              "Condition": {
                  "StringEquals": {
                      "s3:x-amz-acl": "bucket-owner-full-control",
                      "aws:SourceArn": "arn:aws:cloudtrail:us-east-1:232538551827:trail/proposal-orchestrator-bedrock-trail"
                  }
              }
          },
          {
              "Sid": "DenyUnencryptedObjects",
              "Effect": "Deny",
              "Principal": "*",
              "Action": "s3:PutObject",
              "Resource": "arn:aws:s3:::proposal-orchestrator-cloudtrail-232538551827/*",
              "Condition": {
                  "StringNotEquals": {
                      "s3:x-amz-server-side-encryption": "aws:kms"
                  }
              }
          },
          {
              "Sid": "DenyInsecureTransport",
              "Effect": "Deny",
              "Principal": "*",
              "Action": "s3:*",
              "Resource": [
                  "arn:aws:s3:::proposal-orchestrator-cloudtrail-232538551827",
                  "arn:aws:s3:::proposal-orchestrator-cloudtrail-232538551827/*"
              ],
              "Condition": {
                  "Bool": {
                      "aws:SecureTransport": "false"
                  }
              }
          }
      ]
  }
  ---- END trail_bucket_policy.json ----

  Notes on the policy:
  - AWSCloudTrailAclCheck: CloudTrail checks bucket ACL before writing.
    SourceArn condition scopes it to our specific trail.
  - AWSCloudTrailWrite: Allows CloudTrail to write log files under the
    configured prefix. SourceArn + bucket-owner-full-control conditions.
  - DenyUnencryptedObjects: Rejects any PutObject without KMS encryption.
    CloudTrail always writes with aws:kms, so this blocks non-CloudTrail
    unencrypted writes.
  - DenyInsecureTransport: Rejects any request over plain HTTP.

  Apply the policy:

  aws s3api put-bucket-policy \
    --bucket "${BUCKET_NAME}" \
    --policy file://trail_bucket_policy.json

  ============================================================================
  Step 4: Configure S3 Lifecycle Policy
  ============================================================================

  Save the following to lifecycle_policy.json:

  ---- BEGIN lifecycle_policy.json ----
  {
      "Rules": [
          {
              "ID": "proposal-orchestrator-cloudtrail-lifecycle",
              "Status": "Enabled",
              "Filter": {
                  "Prefix": "cloudtrail/proposal-orchestrator/"
              },
              "Transitions": [
                  {
                      "Days": 90,
                      "StorageClass": "GLACIER_IR"
                  }
              ],
              "Expiration": {
                  "Days": 365
              },
              "NoncurrentVersionExpiration": {
                  "NoncurrentDays": 30
              }
          }
      ]
  }
  ---- END lifecycle_policy.json ----

  Notes:
  - GLACIER_IR (Glacier Instant Retrieval) after 90 days — cost-optimized
    but still allows immediate read if needed for audit.
  - Permanent deletion after 365 days. Adjust if institutional policy
    requires longer retention.
  - NoncurrentVersionExpiration after 30 days cleans up old versions
    (versioning is enabled for integrity, but old versions don't need
    indefinite retention).

  Apply:

  aws s3api put-bucket-lifecycle-configuration \
    --bucket "${BUCKET_NAME}" \
    --lifecycle-configuration file://lifecycle_policy.json

  ============================================================================
  Step 5: Create the CloudTrail Trail
  ============================================================================

  aws cloudtrail create-trail \
    --name "proposal-orchestrator-bedrock-trail" \
    --s3-bucket-name "${BUCKET_NAME}" \
    --s3-key-prefix "cloudtrail/proposal-orchestrator" \
    --kms-key-id "arn:aws:kms:us-east-1:232538551827:key/887638e8-358b-4664-9270-368aec0ea1f1" \
    --is-multi-region-trail \
    --enable-log-file-validation \
    --no-include-global-service-events \
    --region us-east-1 \
    --output json

  IMPORTANT: Use the full KMS key ARN (not the alias) for --kms-key-id.
  CloudTrail requires the key ARN for encryption configuration.

  Wait — regarding --is-multi-region-trail and --no-include-global-service-events:

  The hardening plan says Multi-region: No. Use these flags instead:

  aws cloudtrail create-trail \
    --name "proposal-orchestrator-bedrock-trail" \
    --s3-bucket-name "${BUCKET_NAME}" \
    --s3-key-prefix "cloudtrail/proposal-orchestrator" \
    --kms-key-id "arn:aws:kms:us-east-1:232538551827:key/887638e8-358b-4664-9270-368aec0ea1f1" \
    --no-is-multi-region-trail \
    --include-global-service-events \
    --enable-log-file-validation \
    --region us-east-1 \
    --output json

  Notes:
  - --no-is-multi-region-trail: Single-region trail (us-east-1 only).
  - --include-global-service-events: Captures IAM, STS, and other global
    service events (important for tracking role assumption).
  - --enable-log-file-validation: Enables digest files for tamper detection.
  - --kms-key-id: Full ARN of the CMK from CG4.

  Step 7: Trigger a Test Bedrock Call and Verify Event Capture
  ============================================================================

  Connect to instance i-0045af36dbf5f1272 via SSM and make a Bedrock call:

  aws bedrock-runtime converse \
    --model-id us.anthropic.claude-sonnet-4-6 \
    --messages '[{"role":"user","content":[{"text":"Say OK"}]}]' \

  aws cloudtrail lookup-events \
    --lookup-attributes AttributeKey=EventName,AttributeValue=Converse \

    --region us-east-1 \
    --output json

  aws cloudtrail lookup-events \
    --lookup-attributes AttributeKey=EventName,AttributeValue=InvokeModel \
    --max-results 5 \
    --region us-east-1 \
    --output json

  Expected: At least one event showing the Bedrock call with caller identity
  matching assumed-role/proposal-orchestrator-ec2-ssm-role.

  Note: CloudTrail event delivery can take 5-15 minutes. If no events appear
  immediately, wait and retry. Do NOT re-create the trail — just wait.

  ============================================================================
  Troubleshooting
  ============================================================================

  "Insufficient permissions to create trail with KMS encryption"
    -> Verify KMS key policy has AllowCloudTrailEncryption statement with
       the correct trail SourceArn. Check CG4 evidence KMS-E03.

  "S3 bucket policy does not allow CloudTrail to write"
    -> Apply the bucket policy (Step 2) BEFORE creating the trail (Step 5).
       CloudTrail validates the bucket policy during create-trail.

  "No events in lookup-events after test call"
    -> CloudTrail delivery takes 5-15 minutes. Wait and retry.
    -> Verify IsLogging: true with get-trail-status.
    -> Try both EventName=Converse and EventName=InvokeModel.
