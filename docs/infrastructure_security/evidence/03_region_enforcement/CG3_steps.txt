  Steps to Complete CG3

  Only 2 things need to be done:

  Step 1: Actual negative region test from deployment host

  Connect to instance i-0045af36dbf5f1272 via SSM and run:

  # REG-E03: Attempt Bedrock call to unapproved region (should fail)
  {
    echo "=== REG-E03: Negative Region Test ==="
    echo "Date: $(date -u)"
    echo ""
    echo "--- Attempt: us.anthropic.claude-sonnet-4-6 in ap-southeast-1 ---"
    aws bedrock-runtime converse \
      --model-id us.anthropic.claude-sonnet-4-6 \
      --messages '[{"role":"user","content":[{"text":"Say OK"}]}]' \
      --inference-config '{"maxTokens":10}' \
      --region ap-southeast-1 2>&1
    echo ""
    echo "--- Attempt: direct model ID in ap-southeast-1 ---"
    aws bedrock-runtime invoke-model \
      --model-id anthropic.claude-sonnet-4-20250514-v1:0 \
      --content-type application/json \
      --body '{"anthropic_version":"bedrock-2023-05-31","max_tokens":10,"messages":[{"role":"user","content":"test"}]}' \
      --region ap-southeast-1 \
      /dev/null 2>&1
    echo ""
    echo "--- Control: same call in us-east-1 (should succeed) ---"
    aws bedrock-runtime converse \
      --model-id us.anthropic.claude-sonnet-4-6 \
      --messages '[{"role":"user","content":[{"text":"Say OK"}]}]' \
      --inference-config '{"maxTokens":10}' \
      --region us-east-1 2>&1
  } 2>&1 | tee /tmp/REG-E03-negative-region-test.txt

  Expected output:
  - ap-southeast-1 calls: AccessDeniedException or connection failure (no VPC endpoint for that region)
  - us-east-1 call: success with model response

  Step 2: Check if account is in an AWS Organization

  Run from CloudShell or local CLI:

  # Check if account is in an Organization
  aws organizations describe-organization --output json 2>&1

  # If the above succeeds, list SCPs
  aws organizations list-policies --filter SERVICE_CONTROL_POLICY --output json 2>&1

  If the account is not in an Organization, DC-40 is NOT_APPLICABLE. If it is, we need to check for region-restriction SCPs.
